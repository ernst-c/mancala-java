# Mancala
This project was done to improve programming proficiency. The mvc branch consists partially of pre-existing code.

This repository contains two branches: 
- mainline --> OO implementation of mancala domain
- mvc --> full stack implementation of mancala domain 


## Repository structure

In this repository, we find the following files and directories.

```
api
   *Java subproject for running the webserver*
client
   *Our front-end*
domain
   *Java subproject for the Mancala domain*
persistence
   *Java subproject for interacting with the database*
.gitignore
README.md
settings.gradle
...
```
